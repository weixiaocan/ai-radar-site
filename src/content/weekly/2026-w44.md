## 本周最值得亲自看的内容

### 🥇 Top 1: [Building ChatGPT for Finance — Joseph Kim, OpenAI&#39;s Head of Financial Services](https://www.youtube.com/watch?v=v-d1WTqIULs)

**Latent Space**

这期嘉宾是 OpenAI 金融服务负责人 Joseph Kim，他刚在纽约 AI Finance 发表主题演讲，核心议题是 ChatGPT for financial services 这款企业级产品，以及模型能力趋势线对产品构建者的意义。

- 他透露 95% 的产品构建工作其实任何创业公司都能做，真正关键的是补上 Codex 到不了的那 20%，并直言「会有十亿美元级的生意建在 ChatGPT plugin 之上」。
- 他讲了一个反直觉的产品决策：测试发现部分大牌 MCP 的错误率超过 40%，所以宁可把数据搬进产品内部端到端控制，客户最买账的恰恰是数据。
- 他解释了 Codex 在金融、法律、销售场景的采用率原本几乎为零，在 Codex desktop app 发布后突然跳到 90%，说明产品与模型能力必须共同开发。

你正在把 AI 应用工程落到具体业务里，这些关于 20% 增量、数据控制和采用曲线的判断，只有听原话才能抓住语气和取舍逻辑，文字摘要会把这些细节磨平。

### 🥈 Top 2: [Everyone Has the Same AI Models. Here&#39;s What Sets Agents Apart - Richmond Alake, Oracle](https://www.youtube.com/watch?v=1_lX0m64-aI)

**AI Engineer**

Richmond Alake 在大多数人还没听说过 agent memory 时就在讲它，这期他提出控制面之后的下一层是 intelligence plane：agent 知道什么、记得什么、被允许看到什么，以及它如何变得更好。

- 他用二战破译员推断出「AF」就是 Midway 的例子，说明拥有和别人相同的信息并不等于拥有智能。
- 他演示了一个用本体和语义层搭建的 agent，用 32K token 就能 99% 答对，而朴素 agent 需要 200K。
- 他还讲到 Oracle 的 agent memory 包、深度数据安全、私有推理，以及为记忆路由微调小型决策模型。

你正在转向 AI 应用工程，这些关于记忆、权限与 token 效率的取舍，只看文字摘要很难体会其中的工程细节。嘉宾稀缺、观点反共识、技术深度高，值得你亲自花 1.5 小时看完。
